# Internacionalización

Sin librería. El locale vive en la URL, así el HTML prerenderizado y la app hidratada siempre coinciden y cada idioma tiene su propia URL indexable.

| URL                              | Locale                      |
| -------------------------------- | --------------------------- |
| `/`, `/about`, `/blog/x`         | `es` (default, sin prefijo) |
| `/en`, `/en/about`, `/en/blog/x` | `en`                        |
| `/es/about`, `/fr/about`         | no existen → 404            |

## Piezas

- **`src/i18n/config.ts`** es la fuente única de `LOCALES`, `DEFAULT_LOCALE` y `LOCALE_TAGS`. Lo leen rutas, prerender, SEO y sitemap. Helpers: `localizePath`, `stripLocale`, `localeFromPathname`, `isLocale`.
- **`src/routes.ts`** monta cada página una vez por locale con un `id` propio (`es.about`, `en.about`). No hay segmento opcional `:lang?`: una URL de idioma inválido nunca llega a una página.
- **`src/i18n/dictionaries/es.ts`** define el tipo `Dictionary` (`typeof es`). `en.ts` se tipa con él: si falta una clave, el build falla.
- **`useI18n()`** devuelve `{ locale, t, href }`. `href('/about')` produce `/about` o `/en/about` según el locale activo.
- **`getDictionary(locale)`** sirve en `meta`/`loader`, donde no hay hooks.
- **`getRouteLocale(request)`** da el locale en un `loader`. Quita el sufijo `.data` de las peticiones de datos: `/en.data` es `en`.
- **`<html lang>`** se calcula en `root.tsx` desde la URL.
- **Selector de idioma** (`site-header.tsx`): enlaza a la misma página en cada locale, con `hrefLang` y `lang`.

## Contenido

El contenido largo (posts) vive en `src/content/<locale>/*.json` y se valida con zod en el build (`src/types/post.ts`). Los slugs se comparten entre locales: así hreflang empareja las versiones. `src/actions/posts.test.ts` lo verifica.

## Agregar un idioma

1. Agrega el código a `LOCALES` y su tag a `LOCALE_TAGS` en `src/i18n/config.ts`.
2. Crea `src/i18n/dictionaries/<código>.ts` tipado con `Dictionary` y regístralo en `src/i18n/index.ts`.
3. Crea `src/content/<código>/posts.json` y agrégalo al mapa `RAW` de `src/actions/posts.ts`.
4. `npm run build`: rutas, prerender, hreflang y sitemap se generan solos.

## Quitar i18n (sitio de un solo idioma)

Deja `LOCALES = ['es']`. El prefijo desaparece, no se emiten alternates (`buildMeta` solo los pone con más de un locale) y el selector muestra un solo enlace. Puedes borrarlo de `site-header.tsx`.
